# Frustum

**한밤의 캠핑장, 손전등 술래잡기.** 후드를 쓴 아이들이 달빛 아래 캠핑장에서 손전등으로 서로를 찾는다.
손전등이 비추는 곳만 따뜻하게 밝고, 그 밖은 어둠이다. 보이는 것은 내(그리고 팀원의) 시야뿐이고,
시야 밖의 상대는 **서버가 아예 보내지 않는다.**

- 클라이언트: Three.js(WebGL2) — 모바일 브라우저에서 바로 실행, PWA 매니페스트 포함
- 서버: Node.js + `ws` — 권위 서버(30Hz 시뮬레이션, 15Hz 스냅샷)
- 빌드 단계 없음

## 실행

```bash
npm install
npm start          # http://localhost:3000  (PORT 환경변수로 변경)
npm test
```

같은 네트워크의 휴대폰에서 `http://<PC IP>:3000` 으로 접속하면 된다. 혼자 접속해도 봇이 채워진다.

메뉴에는 두 가지 시작 방법이 있다.

- **혼자 하기 (봇전)**: 서버 없이 브라우저 안에서 서버 로직(`server/game.js`)을 직접 실행한다. 정적 호스팅(GitHub Pages)만으로 동작한다.
- **온라인 접속**: WebSocket 서버에 접속한다. 같은 호스트의 `/ws`가 기본이고, `?server=wss://호스트` 로 다른 서버를 지정할 수 있다.

## 설정

메뉴의 설정 버튼이나 게임 중 ⚙️ 버튼으로 연다. 기기에 저장된다.

- 조이스틱 고정(항상 같은 자리에 표시), 왼손 모드(조이스틱과 버튼 좌우 반전)
- 회전 감도, 효과음 크기, 진동, 성능 정보 표시
- 게임 중에는 "게임 나가기"로 메뉴로 돌아간다

## Render 배포 (멀티플레이 서버)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/wifttu/Frustum)

1. 위 버튼을 누르고 Render 에 GitHub 계정으로 로그인한다(저장소가 비공개면 Render 에 저장소 접근을 허용한다).
2. `render.yaml`(Blueprint) 설정이 그대로 뜬다. **Apply** 를 누르고 몇 분 기다린다.
3. `https://frustum-xxxx.onrender.com` 같은 주소가 생긴다.
4. 게임의 **설정 → 온라인 서버 주소**에 그 주소를 붙여 넣고 **연결**을 누른다. "연결됐어요"가 뜨면 로비에서 온라인으로 시작한다.
   주소는 그 기기에 저장된다. 초대 링크에는 서버 주소가 함께 담긴다.
5. 기본 서버는 `client/settings.js` 의 `DEFAULT_SERVER` 로 정해져 있다(현재 `frustum.onrender.com`). 다른 서버를 쓰려면 이 값을 바꾸고 푸시한다.

무료 플랜은 15분간 접속이 없으면 잠들고, 다시 깨어나는 데 최대 1분 걸린다(클라이언트가 자동으로 재시도한다).
Render 주소를 직접 열어도 서버가 서빙하는 같은 게임이 뜨고, 거기서는 주소 설정 없이 온라인이 된다.

## GitHub Pages 배포

`main`에 푸시하면 `.github/workflows/pages.yml`이 테스트 후 `npm run build:pages`로 `dist/`를 만들어 배포한다.
저장소 **Settings → Pages → Source를 "GitHub Actions"** 로 한 번만 바꿔 두면 된다.
주소는 `https://<사용자>.github.io/Frustum/` 이다. Pages에는 서버가 없으므로 이 주소에서는 "혼자 하기"만 된다.
멀티플레이는 `npm start` 서버를 Render 등에 올리고 `https://<사용자>.github.io/Frustum/?server=<서버 호스트>` 로 접속한다.

| | 이동 | 회전 | 손전등 | 구르기 | 조명탄 |
|---|---|---|---|---|---|
| 모바일 | 왼쪽 드래그(조이스틱) | 오른쪽 드래그 | 손전등 버튼 | 구르기 버튼 | 조명탄 버튼 |
| PC | WASD | 마우스 드래그 / ←→ / Q·E | Space | Shift | F |

## 게임 규칙

한 방에 8명(모자라면 봇)이 들어간다. 메뉴에서 규칙 4가지 × 인원 구성 2가지를 고른다(서버는 조합마다 방 하나).

| 규칙 | 부활 | 승리 조건 |
|---|---|---|
| 데스매치 | 3초 후 부활 | 3분 동안 킬이 가장 많은 사람/팀 |
| 점수제 데스매치 | 3초 후 부활 | 목표 킬(개인전 10, 팀전 15)을 먼저 달성. 5분이 지나면 킬 1위 |
| 모닥불 점령 | 3초 후 부활 | 가운데 모닥불 둘레를 지켜 목표 점수(개인전 25, 팀전 35)를 먼저 채운다. 3분이 지나면 점수 → 킬 |
| 서바이벌 | 없음 | 마지막 생존자/팀. 2분이 지나면 생존자 수 → 킬 수 |

- **개인전**: 8명 각자 싸운다. 시야 공유 없음.
- **2인 팀전**: 2명씩 4팀. 팀원과 시야를 공유한다.
- **독구름**(서바이벌 전용): 시작 15초 뒤부터 맵 가장자리에서 안쪽으로 조여 와 100초에 중앙 14m × 14m만 남는다. 구름 속에 3초 머물면 탈락하고, 밖으로 나오면 천천히 회복한다. 구름은 시야와 무관하게 항상 보인다.
- **모닥불 점령**: 맵마다 가운데에서 가장 가까운 트인 곳(`hillOf`, `shared/map.js`)에 큰 모닥불이 있다. 반지름 3.5m 둘레 안에
  살아 있는 편이 우리 편뿐이면 1초에 1점, 다른 편도 있으면 "쟁탈 중"이라 아무도 점수를 얻지 못한다. 둘레와 빛기둥은 어둠 속에서도 보이고
  차지한 편의 색(우리 초록, 상대 빨강, 쟁탈 중 깜빡임)으로 바뀐다. 미니맵에도 표시. 봇도 모닥불로 모여 지킨다.
- 동률이면 무승부. 시작 후 3초 동안은 공격할 수 없다.
- **결과 화면의 다시하기 / 나가기**: 혼자 하기는 다시하기를 누를 때까지 결과를 보여 주고, 누르면 바로 다음 판.
  온라인은 8초 뒤 다음 판이 자동으로 시작되고, 방의 사람이 모두 다시하기를 누르면 더 일찍 시작한다(결과는 최소 2.5초).
  나가기는 로비로(친선 방이면 방으로) 돌아간다. 사람이 둘 이상인 방은 "🙋 다시하기 1/3명"처럼 누른 사람 수를 보여 준다.
- **최근 전적(로비 🎯 미션 → 최근 전적)**: 끝까지 한 판이 최근 10판까지 기기에 남는다(백업 코드에도 포함).
  위에 요약(승패, 승률, 평균 순위, 최고 순위, 잡은 수), 아래에 판마다 결과·순위·규칙·맵·혼자/온라인·잡은 수·랭크 변화.
  순위는 순위표 점수 기준이고 점수가 같으면 같은 순위. 규칙은 `shared/history.js`.
- **결과 시상대**: 판이 끝나면 1~3등(순위표 점수)이 입은 의상 그대로 시상대에 올라 승리 포즈를 한다(1등 만세 점프, 2등 손 흔들기,
  3등 박수, 꽃가루). 가로 화면에서는 시상대가 왼쪽, 결과표와 보상이 오른쪽. `client/podium.js`.
- 라운드 도중에 들어온 사람은 봇의 자리를 이어받는다.
- **손전등 빔**: 6m, 40° 원뿔 안에서 벽에 가리지 않은 적에게 피해를 준다. 쿨다운 1.5초.
- **구르기**: 이동 방향(가만히 있으면 앞)으로 0.3초 동안 약 4.5m 이동, 그동안 무적. 구르는 중에는 공격 불가. 쿨다운 3초.
- **조명탄**: 앞으로 최대 8m 던져 4초 동안 반경 7m를 팀 시야로 밝힌다(벽 그림자 적용). 우리 팀에게만 보인다. 쿨다운 12초.
- 스킬 버튼에는 남은 쿨다운이 숫자로 표시된다.
- **체력과 성장**: 체력 100, 손전등 한 번에 34 피해(기본 세 번에 쓰러짐). 4초 동안 맞지 않으면 회복한다.
  - 맵에 떠다니는 **경험치 구슬**은 세 종류다: 작은 노란 구슬(6), 중간 초록 구슬(18), 크고 보랏빛으로 빛나는 구슬(50, 드묾).
    중간·큰 구슬을 먹으면 머리 위에 +XP 숫자가 뜬다. 상대를 맞히거나 잡아도 경험치를 얻는다.
  - **자석**: 줍는 거리(1.7m, 반디 +2m, 자석 강화 +1.6m) 바깥 1.8m 안의 구슬은 플레이어 쪽으로 파르르 떨리며 끌려가고,
    먹히는 순간 자석에 붙듯 가속하며 몸으로 날아와 쏙 들어간다(다른 플레이어가 먹을 때도 보인다).
  - **왕귀(빠른 성장)**: 레벨마다 체력 +8, 피해 +4%가 저절로 붙고, 몸집도 커진다(Lv 20에서 약 1.4배).
    쓰러진 쪽은 모은 경험치의 60%와 레벨 보너스를 큰 구슬 여러 개로 흘린다. 높은 레벨을 잡으면 레벨 차이마다 경험치 +40%(현상금).
    1등의 머리 위에는 👑 왕관이 뜬다.
  - 경험치 구슬은 각진 보석 모양으로 빙글빙글 돌며 떠 있고 바닥에 그림자가 진다. 레벨업하면 황금빛 기둥이 솟는다.
- **치트 모드(설정)**: 코인 무한, 무적, 경험치 5배, 쿨타임 1/4, 이동 +30%를 하나씩 켜고 끈다.
  게임 안 치트는 사람이 나 혼자일 때(혼자 하기, AI 상대)만 서버가 적용하고, 다른 사람이 들어오면 바로 꺼진다.
  코인 무한을 끄면 켜기 전 코인으로 돌아간다.
  - 레벨이 오를 때마다 **강화 카드 3장 중 1장**을 고른다(최대 Lv 20): 튼튼한 몸, 강한 빛, 긴 빛, 넓은 빛,
    빠른 충전, 가벼운 발, 스킬 달인, 회복력, 따뜻한 빛(흡혈), 반딧불 자석. 강화는 서버 판정과 화면(빔 크기)에 모두 반영된다.
  - 밸런스(봇 40판 시뮬레이션): 캐릭터별 K/D 0.76~1.20, 평균 레벨 30초 4.6 / 1분 7.0 / 2분 10.2 / 3분 12.5, 1등은 Lv 16 안팎.
  - 레벨과 강화는 라운드마다 초기화된다(데스매치는 부활해도 유지). 메뉴의 **모험가 레벨**은 기기에 계속 쌓인다.
  - 손전등 기본 충전 시간은 체력제에 맞춰 1.5초로 줄였다(강화로 더 줄어든다).
- **캐릭터**: 능력이 다른 7종. 플레이로 얻은 경험치 4당 코인 1을 받고, 메뉴의 캐릭터 상점에서 구매해 고른다.
  탐험가(기본, 체력 115), 번개(이동 +15%, 충전 -20%), 곰돌이(체력 115, 방패), 올빼미(긴 사거리), 반디(경험치 +30%), 그림자(피해 +20%, 은신), 약초꾼(회복 1.5배, 흡혈 8%).
  선택 화면에서는 캐릭터가 3D로 줄지어 서고, 고른 캐릭터의 능력 설명과 능력치 그래프(체력·속도·공격·사거리)가 나온다.
  내 캐릭터는 캐릭터 고유 색 후드를 입는다(아군은 파랑, 적은 빨강 그대로).
  계정이 없어서 코인과 보유 캐릭터는 기기(localStorage)에 저장되며, 서버는 구매 여부를 검증하지 않는다.
- **고유 스킬**: 두 번째 버튼은 캐릭터마다 다르다. 탐험가 구르기(무적 회피) / 번개 질주 / 곰돌이 방패(2.5초 무적) /
  올빼미 매의 눈(4초간 주변 15m 사방 시야) / 반디 끌어오기(주변 반딧불 흡수) / 그림자 은신(3.5초) / 약초꾼 치유(나와 아군 +35).
  - 스킬마다 자세와 효과가 있다(과하지 않게): 질주는 몸을 숙이고 바람 줄기, 방패는 웅크리며 가장자리가 빛나는 보호막,
    매의 눈은 이마에 손을 얹고 둘러보며 잔잔한 고리, 끌어오기는 두 팔을 쭉 뻗었다가 몸을 젖히며 한 걸음 물러나 끌어당기면
    11m 안의 구슬이 꼬리를 남기며 소용돌이처럼 돌아 빨려 들고 다 모이면 몸에서 빛이 퍼진다,
    은신은 웅크리며 연기(풀릴 때도 작은 연기), 치유는 두 팔을 들고 초록 고리와 반짝이(치유받은 아군에게도), 조명탄은 던지는 동작.
  이동에 영향을 주는 구르기·질주는 공용 시뮬레이션에서, 나머지는 서버에서 효과를 적용한다.
- **로비**: 가운데에 내 캐릭터(3D), 왼쪽 위 프로필(닉네임, 모험가 레벨), 오른쪽 위 코인과 설정, 왼쪽에 캐릭터·상점·친구·출석,
  아래에 모드·맵 선택 카드와 게임 시작 버튼(혼자/온라인 전환).
- **전체 화면과 앱 설치**: 화면을 한 번 누르면 전체 화면으로 바뀌어 주소창과 아래 네비게이션 바가 사라진다(설정에서 끌 수 있다).
  홈 화면에 추가하면(안드로이드는 설정의 "📲 설치", 아이폰은 사파리 공유 → 홈 화면에 추가) 처음부터 주소창 없이 앱처럼 열린다.
  `client/sw.js` 서비스 워커는 항상 네트워크를 먼저 쓰고, 오프라인일 때만 캐시로 연다.
- **판 결과**: 라운드가 끝나면 레벨, 잡은 수, 이번 판 경험치와 코인을 보여 준다. 로비에는 잔잔한 배경음악(설정에서 끄기), 달리거나 구를 때 흙먼지가 인다.
- **프로필 아이콘**: 로비의 아이콘을 눌러 고른다. 기본 12종에 더해 가진 캐릭터와 의상의 아이콘이 열린다.
- **온라인 매칭**: 공개 방은 규칙 × 인원 조합마다 하나씩이다. 사람이 모자란 자리는 `AI-n` 봇이 채우고, 사람이 들어오면 봇이 자리를 넘긴다.
  모드 선택 창에 지금 접속 인원이 표시되고, "사람 많은 방으로" 버튼이 가장 붐비는 방을 골라 준다(`GET /rooms`).
- **친선 게임 방**: 로비의 "친선 게임 만들기"로 방을 만든다. 방 코드(5자) 또는 초대 링크(`?party=코드`)로 들어온다.
  - 8칸 슬롯(2인 팀전은 2칸씩 4팀, 개인전은 8칸). 빈칸을 누르면 그 자리로 옮기고, 같은 팀 칸끼리 같은 팀이 된다.
  - 방장: 규칙·인원·맵·빈자리(AI로 채우기 / 사람만) 변경, 내보내기, 시작. 방장이 나가면 다음 사람이 방장이 된다.
  - 다른 사람은 "준비"를 눌러야 시작할 수 있다. 설정이 바뀌면 준비가 풀린다. 빠른 채팅(정해진 문구 8개)으로 말풍선을 띄운다.
  - 게임이 끝나거나 "방으로 돌아가기"를 누르면 방으로 돌아오고, 진행 중인 게임에는 "게임 참가"로 늦게 들어갈 수 있다.
- **친구**: 기기마다 6자리 친구 코드가 생긴다. 코드를 주고받아 추가하면 접속 상태(접속 중 / 방에 있음 / 게임 중 / 오프라인)가 보이고,
  방에 있을 때 "초대"를 누르면 친구 화면에 초대 알림이 뜬다(친구가 온라인에 연결되어 있어야 한다).
  함께 플레이한 사람은 "최근 함께한 플레이어"에 친구 코드와 함께 남아 바로 추가할 수 있다. 계정이 없어 목록은 기기에 저장된다.
- **맵 고르기**: 혼자 하기와 친구 방에서는 맵을 고정할 수 있다. 공개 온라인 방은 순환한다.

  (다른 사람에게는 아군 파랑, 적 빨강). 서버는 그 캐릭터의 의상만 받는다. 예전 공용 의상은 같은 등급의 새 의상으로 자동으로 바뀐다.

## Render 배포 (멀티플레이 서버)

`render.yaml`(Blueprint)이 들어 있다. render.com 가입 → **New → Blueprint** → 이 저장소 선택 → Apply.
몇 분 뒤 `https://frustum-xxxx.onrender.com` 같은 주소가 생기고, 그 주소를 열면 서버가 직접 서빙하는 게임에서 "온라인 접속"이 바로 된다.
GitHub Pages 에서도 온라인이 되도록 `client/settings.js` 의 `DEFAULT_SERVER` 에 서버 주소가 들어 있다.
무료 플랜은 15분간 접속이 없으면 잠들고, 다시 깨어나는 데 최대 1분 걸린다(클라이언트가 자동으로 재시도한다).

`main`에 푸시하면 `.github/workflows/pages.yml`이 테스트 후 `npm run build:pages`로 `dist/`를 만들어 배포한다.
저장소 **Settings → Pages → Source를 "GitHub Actions"** 로 한 번만 바꿔 두면 된다.
주소는 `https://<사용자>.github.io/Frustum/` 이다. Pages에는 서버가 없으므로 이 주소에서는 "혼자 하기"만 된다.
멀티플레이는 `npm start` 서버를 Render 등에 올리고 `https://<사용자>.github.io/Frustum/?server=<서버 호스트>` 로 접속한다.

## 게임 규칙

- **손전등 빔**: 7m, 40° 원뿔 안에서 벽에 가리지 않은 적을 처치한다. 쿨다운 0.8초.
- **구르기**: 이동 방향(가만히 있으면 앞)으로 0.3초 동안 약 4.5m 이동, 그동안 무적. 구르는 중에는 공격 불가. 쿨다운 3초.
- **조명탄**: 앞으로 최대 8m 던져 6초 동안 반경 7m를 팀 시야로 밝힌다(벽 그림자 적용). 우리 팀에게만 보인다. 쿨다운 12초.
- **라운드**: 팀 킬 20(개인전 10)에 먼저 도달하면 승리, 6초 후 점수를 초기화하고 다음 라운드.
- **사운드**: 오디오 파일 없이 Web Audio로 합성. 시야 안의 빔/구르기는 위치에 따라 좌우로 들린다.
  적이 시야에 들어오면 경고음이 난다. 우측 상단 🔊 버튼으로 끈다.

## 요구사항별 구현

### 1. 시야각 기반 마스킹 — `client/fog.js`
- 캐릭터의 시야 = 수평 FOV 90° · 거리 20m 부채꼴에서 벽 뒤 그림자를 뺀 다각형 (+ 몸 주변 1.6m).
- 매 프레임 이 다각형을 맵 전체를 덮는 512² 텍스처에 그리고, 모든 월드 머티리얼이 자기 월드 좌표로
  그 텍스처를 샘플링한다. 시야 밖은 벽·캐릭터 0%, 바닥 격자만 5% 밝기로 남는다.
- 화면 전체 후처리 패스가 없어서 모바일 GPU 부담이 작다.
- 팀전에서는 살아있는 팀원의 시야 다각형을 MAX 블렌딩으로 합쳐 시야를 공유한다.

### 2. 시야 기반 동기화 — `server/game.js`
- 서버가 팀별로 "보이는 적" 집합을 계산하고(`computeVisibility`), 플레이어마다 그 집합에 속한 적만
  스냅샷에 담는다(`snapshotFor`). 시야 밖 적의 좌표는 클라이언트 메모리에 존재하지 않으므로
  월핵/맵핵으로 읽어낼 것이 없다.
- 스냅샷에서 빠진 플레이어는 클라이언트가 즉시 삭제한다. 로스터와 킬 피드에는 위치가 없다.
- 이동은 서버 권위: 입력값 클램프, 틱당 입력 1개 예산(스피드핵 방지), 회전 속도 제한(순간 360° 스캔 방지),
  초당 메시지 수와 페이로드 크기 제한.
- 클라이언트는 같은 `sim.js`로 자기 이동을 예측·보정하고, 다른 플레이어는 110ms 보간한다.

### 3. 프러스텀 컬링 — `client/main.js`
- 벽은 `InstancedMesh` 1개(드로우콜 1회). 매 프레임 **시야 광선이 닿은 벽 ∩ 카메라 절두체 안의 벽**만
  인스턴스 버퍼에 채운다. 보통 41개 중 6~12개만 그려진다.
- 플레이어는 서버가 보낸 것만 존재하고, 그중 카메라 절두체 밖은 `visible = false`.
- 좌상단 HUD에 fps / 드로우콜 / 그려진 벽·플레이어 수가 표시된다.

### 4. 모바일
- 터치 조이스틱 + 드래그 회전 + 공격 버튼, 가로/세로 화면 모두 지원, 노치 safe-area 대응.
- 픽셀 비율 최대 2로 제한, 프레임이 떨어지면 렌더 해상도를 자동으로 낮추고 여유가 생기면 복구.
- 그림자 맵·안티앨리어싱·후처리 없음, 지오메트리와 머티리얼 공유.
- 스토어 배포가 필요하면 `client/`를 Capacitor 같은 웹뷰 래퍼로 감싸면 된다.

## 설정

`shared/config.js`에서 조정한다. 서버는 모드별로 방을 하나씩 운영한다.

## 알아둘 점

- 맵이 평지 + 수직 벽이라 시야 판정은 XZ 평면에서 한다(절두체의 위/아래 평면은 아무것도 자르지 않음).
  높낮이가 있는 맵으로 확장하려면 `vision.js`에 수직 판정을 추가해야 한다.
- 시야 경계에서 적이 갑자기 튀어나오지 않도록 서버가 0.3m 여유(`VIS_MARGIN`)를 두고 보낸다.
- 혼자 하기 모드는 서버 로직이 클라이언트에서 돌기 때문에 서버 쪽 시야 필터링의 치트 방지 효과는 없다(온라인 모드에서만 유효).
- 스냅샷은 JSON이다. 인원이 크게 늘면 바이너리 인코딩과 델타 압축이 다음 단계다.
- 방은 모드당 1개(최대 8명)이고, 매치메이킹·계정·재접속 처리는 없다.
